## 费曼技巧（四步）

```text
1. 选概念：挑一个想学懂的知识点
2. 讲出来：假装教给一个小白，用大白话讲
3. 找漏洞：卡壳、含糊的地方 = 没学懂的地方
4. 回炉：回到资料补漏洞，再讲一遍，直到顺畅
```

判断标准：**能不能不看资料，把"为什么"讲明白**。

## 主动回忆（Active Recall）

- 学习 ≠ 重读：合上书，**凭记忆写/说**出要点，再对照
- 测试效应：回忆一次 ≈ 重读三次的记忆强度
- 落地：每学一节，先合书自测再继续

## 间隔重复（Spaced Repetition）

- 遗忘曲线要求：**在快忘的时候复习**（1 天 → 3 天 → 7 天 → 30 天）
- 工具：Anki / 个人知识库里的"复习清单"
- 刷题比读题有效：回忆越费力，记忆越牢

## 个人知识库的搭建方法

```text
采集 → 整理 → 关联 → 输出
```

1. **采集**：一个 Inbox（收件箱），随手扔进去，不分类
2. **整理**：定期（每周）归入分类：编程 / 科研 / AI / 效率 / 学习
3. **关联**：给每条笔记打标签、链接相关条目（形成网状知识）
4. **输出**：把笔记写成文章/教程公开 —— 输出的知识才是自己的

这套知识库本身就是例子：速查手册（检索型）+ 流程指南（操作型）混合。

## 每周复盘清单

- [ ] 哪些没搞懂？下周怎么补？
- [ ] 哪些值得沉淀成笔记/文章？
- [ ] 下周最重要的一件事是什么？
