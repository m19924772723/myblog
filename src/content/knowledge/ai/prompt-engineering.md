## 三段式万能模板

```text
【角色】你是一名资深 X（背景决定专业度）
【任务】请帮我做 Y（越具体越好，含输入输出格式）
【约束】要求 Z（长度、风格、不许做的事）
```

示例：

```text
你是一名资深论文润色专家。
请润色下面这段论文摘要，保持专业学术语气。
约束：输出 150 字以内；保留所有技术术语；不要改写数值。

原文：……
```

## Few-shot：给例子比讲道理有效

```text
把下面句子分类为「正面/负面/中性」：
例1：效果炸裂，强烈推荐！ → 正面
例2：文档看不懂，差评。 → 负面
例3：功能完整，但上手有门槛。 → 中性
现在：这个模型训练时间太长，不过精度不错。 →
```

## 思维链：复杂问题让它先想

```text
我有一篇论文需要 1200 字实验分析，帮我先列出分析框架，
再按框架逐段撰写，每一段先给出统计数字再下结论。
```

不加"请一步一步想"也能引导，关键是**要求输出中间步骤**。

## 让输出稳定的技巧

1. **指定格式**：JSON / 表格 / 列表，给 schema 示例
2. **长度限制**：给字数或行数，别只说"简短"
3. **否定式约束**："不要使用'惊艳''神器'等营销词"
4. **提供上下文**：把相关材料直接贴进来，别让它猜
5. **一次只问一件事**：多任务拆成多次对话

## 常见失败与对策

| 现象 | 对策 |
|---|---|
| 回答泛泛而谈 | 加角色 + 加具体场景 |
| 编造数据/来源 | 要求"只基于我给的资料回答"，注明来源 |
| 忽略某条要求 | 把关键要求放最后再说一遍 |
| 输出格式乱了 | 给一个完整可解析的示例 |

> [!tip]
> 提示词不是玄学：**上下文给足、任务说清、格式受限、例子示范**，大部分问题这样能解决。剩下的就是迭代 —— 每次只改一个变量。
