# 欢迎来到我的博客

你好，我是 ling-ou-pq，一名电子信息 / 人工智能方向的研究生。

这个站点是我的**个人博客 + 工作台**：

- **博客**：学习笔记、实验报告、课程论文、技术随笔，全部真实内容。
- **工作台**：每日待办、每日记录（由本地自动化管线生成，包含 Hermes 会话摘要与当日活动快照）。
- **后台**：访问 `/admin` 可以用图形界面管理全部内容，改动直接提交到 GitHub 仓库。

## 为什么这么搭

我的原则很简单：**记录是真实的，自动化是认真的**。

每天 22:00，本地任务计划程序自动收集我当天的真实活动，生成记录提交到 GitHub——热力图上的绿色格子不是刷出来的，是流水账。

博客与工作台共用一套内容与后台（Decap CMS），写文章和记流水账不需要切工具。

## 接下来会写什么

- 论文写作工作流（真实实验 + 可复现数据）
- AI 工具链使用心得（Hermes、Claude Code、Codex、PI）
- 课程学习笔记

欢迎常来。
